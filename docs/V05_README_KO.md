# Marble Flick v0.5 | 4개 주요 스킬 + 락온 준비 시스템

버전 0.4를 **덮어쓰는 업데이트**입니다. 스탯, CPU Easy/Normal/Hard, 파랑 아래/빨강 위, 슬링샷 발사, 1v1 및 4v4~10v10, 부상, 맵과 장애물은 유지됩니다.

## flickshit에 설치하기

1. 이 압축파일을 열고 `main.py`, `physics.py`, `cpu.py`, `stats.py`, `abilities.py`, `play_windows.bat`, `assets` 등 **안의 파일과 폴더 전체**를 기존 `flickshit` 안으로 복사합니다. 기존 v0.4 코드 파일은 덮어쓰기합니다. 새 MP3 효과음이 이미 있다면 `assets/sfx` 폴더를 그대로 유지하세요.
2. `flickshit/play_windows.bat`를 실행합니다. Python 3.10 이상과 Pygame이 필요하며 Pygame이 없으면 배치 파일이 설치를 시도합니다.
3. 직접 실행: `python -m pip install -r requirements.txt` 다음 `python main.py`.
4. 효과음 점검: `python check_sfx.py`.

## 스킬 슬롯 / 사용법

각 팀은 **스킬 2개**를 장착합니다. 팀 전체가 공유하는 스킬 재사용 대기시간을 사용하며, 한 번의 준비 단계에서 각 팀당 **스킬 하나만** 사용할 수 있습니다.

- 오른쪽 `SKILL LAB`: 왼쪽의 `BLUE`/`RED` 탭으로 편집할 팀을 고릅니다. `1`, `2` 슬롯 버튼으로 장착 위치를 고른 다음 밑의 네 스킬 중 하나를 클릭해서 장착합니다. 동일 스킬 2개는 중복 장착 불가.
- 현재 조종 중인 팀에서는 **1 또는 2 키**로 사용할 스킬 슬롯을 선택합니다.
- **E 키를 누른 다음 자신의 구슬을 왼쪽 클릭**하면 그 구슬에 스킬을 준비합니다. 준비된 똑같은 구슬을 E로 다시 선택하면 취소합니다.
- 공격용 스킬을 준비했다면 **그 구슬을 당겨서** 쏴야 합니다. Brickwall은 내 구슬 하나를 강화하고 **다른 구슬로 쏠 수 있습니다**.
- 방어팀은 현재 Brickwall만 사용 가능합니다. Tiger, Chain, Cola는 공격용입니다.
- 스킬을 미리 지정해도 상대에게 바로 보이지 않습니다. 실제 공개/쿨타임 소모는 두 플레이어가 준비를 끝내고 **LOCK REVEAL**이 일어날 때입니다. 아무도 공격하지 못해 턴을 넘기면 준비해둔 스킬은 소모되지 않습니다.

## 새 락온 / 동시 공개 진행

**25초짜리 공유 준비 시간**입니다.

1. 공격자는 자신의 구슬을 뒤로 당겨 마우스를 놓으면 **바로 발사하지 않고 공격 방향이 잠깁니다(LOCKED)**. 그 상태에서는 조준 방향이 화면에 표시되지 않습니다.
2. 방어자는 Brickwall을 쓰려면 E + 구슬 클릭으로 지정합니다. 아무 스킬을 안 써도 됩니다.
3. 방어자는 **Space** 또는 오른쪽 패널의 **DEFENSE READY** 버튼을 누릅니다.
4. 공격 LOCK과 방어 READY가 모두 맞춰지면 공격 방향과 방어 스킬을 **동시에 보여주고**, 짧은 공개 연출 후 물리 발사합니다.
5. 시간이 끝나면 아직 준비하지 않은 편을 자동 처리합니다. 공격자가 끝내 방향을 정하지 않았으면 턴이 패스됩니다.

**LOCAL 2P 주의:** 한 대의 PC에서 번갈아 조종하므로, 공격자가 먼저 조준을 잠그면 그다음 방어자가 준비하는 순차적인 '핫시트' 방식입니다. 공격 방향은 잠금 뒤 숨겨지지만 앞서 드래그하는 모습을 옆에서 보면 알 수는 있습니다. 향후 하마치 2인 네트워크에서는 두 사람이 각자 화면에서 **동시에** 준비하도록 교체하면 됩니다.

**CPU 대전:** 빨간 팀 CPU가 공격과 방어를 자동 준비합니다. CPU가 공격할 때 파란 팀 플레이어는 수비 스킬을 지정하고 Space로 준비를 마칠 수 있습니다. CPU는 자신이 공격할 때 장착한 공격 스킬을 때때로 사용하며, 방어 시에는 기존 위치 정보로 Brickwall을 고릅니다. 완벽한 심리전 AI는 아닙니다.

## 스킬 세부 규칙

| 스킬 | 종류 | 쿨타임 | v0.5 구현 내용 |
| --- | --- | --- | --- |
| **Brickwall** | 공격 또는 방어 | 6턴 | 구슬 크기 +75%, 회색 돌 재질, 완전 고정 충돌체, 충격·부상·풍압 면역, 공격자를 반사. **내 공격 준비에 설치하면 내 공격 + 다음 상대 공격** 동안 유지, **수비 중 설치하면 현재 공격만** 버팁니다. |
| **Tiger Shot** | 공격 | 7턴 | 해당 샷 속도 +200%(3배), 파워 +200%(3배), 정확도 오차 0°, 나무 장애물 즉시 파괴, 이동 중 근처 구슬을 조금 미는 일회성 풍압. |
| **Chain** | 공격 | 10턴 | 적 구슬을 맞히면 물리 시간이 최대 **1.75초 잠깐 정지**합니다. 이때 **마우스로 다음 진행 방향을 가리키고 E**를 누르면 재가속. 적중할 때마다 다시 가능, 최대 **5번 후속 가속**. 횟수가 늘수록 속도와 추가 파워가 약해집니다. CPU는 다음 적 방향을 자동으로 선택합니다. |
| **Coca Cola Espuma** | 공격 | 7턴 | 해당 구슬이 **정지한 뒤** 반경 약 177픽셀에 충격파를 발생시켜 주변 구슬을 밀어내고 자신은 희생합니다. **아군 마지막 구슬 하나만 남았다면 자신은 살아남습니다.** 발사 중 장외로 떨어지면 폭발하지 않습니다. |

쿨타임의 `턴`은 **파랑 또는 빨강의 공격 한 번이 끝날 때마다 올라가는 전체 공격 턴 번호** 기준입니다. 예: 1턴에 Tiger 사용 시 8턴부터 다시 사용 가능합니다. 이번 버전에서는 실험 편의상 경기 도중에도 장착 스킬을 바꿀 수 있습니다. 다음 매치를 시작하면 쿨타임만 초기화되고 두 슬롯에 장착한 종류는 유지됩니다.

## 검증과 제약

검증: `python -m unittest discover -s tests -v`. 물리엔진의 Brickwall/풍압/나무 파괴/Chain/Cola/쿨타임·락온·동시 공개·CPU 판단을 자동 시험합니다.

**현재 개발 환경에 Pygame이 설치되지 않고 네트워크 설치도 되지 않아, 화면을 띄우고 마우스로 직접 플레이하는 최종 검증은 진행할 수 없었습니다.** Python 문법 검사, 게임 진행 코드 호출, 물리/AI 자동 테스트는 통과했습니다. 사용자 컴퓨터에서 창 레이아웃과 실제 게임 조작은 추가 확인이 필요합니다.

아직 없는 것: 패시브, 클러치 쿨타임 초기화, 공식 저장형 스탯 로드아웃, 하마치 LAN 멀티플레이, EXE 묶기. 이들은 이후 단계에서 추가합니다.
