# Marble Flick v0.8 검증 결과

검증 환경: Linux, Python 3.12.14, Pygame 2.6.1 / SDL 2.28.4, dummy 비디오·오디오 드라이버.
기존 v0.7 커밋 `c76d4c4`를 확장했습니다. EXE는 만들지 않았습니다.

## 실행 결과

- `python -m unittest discover -s tests`: **141개 통과**, 26.834초.
- `python check_sfx.py --headless`: **종료 코드 0**. 제공된 효과음 42개 디코딩 성공. 누락된 효과음은 합성 대체음으로 채널 재생 성공.
- 제공 BGM **11개 모두 SDL 디코딩 및 실제 재생 예약 성공**. 스피커 청취는 포함하지 않습니다.
- 모든 최상위 Python 모듈 구문 검사 통과. `git diff --check` 통과.
- 실제 `Game.run()` 루프에서 메뉴 → 보스 도전 → 전투 → 종료까지 정상 처리.
- 한국어/영어의 메인·LAN·보스·스킨 페이지와 보스 전투 렌더링 확인. 관련 PNG 스크린샷을 같은 폴더에 첨부했습니다.

## LAN 검증

실제 loopback TCP 소켓을 사용했습니다. 단순 함수 모의 테스트가 아닙니다.

- 두 개의 독립 Python 프로세스가 방 생성/접속 → 양쪽 준비 → 3회 공격 턴 → 4턴 도달까지 게임 루프와 전투 렌더링을 수행.
- 방장 물리 상태가 친구 화면에 전달되며 친구가 로컬 물리를 중복 실행하지 않음.
- 비공개 스킬 준비, 조준 공·방향·커브 값·선택 슬롯의 전송 차단. 공개 단계에서는 실제 준비 정보 전달.
- 천안 발동 시 해당 공격자에게 방어 스킬 이름과 정확한 공 ID 전달. 상대 화면에는 천안 내용 숨김.
- 다른 소유자의 공 조작 차단, 이미 확정된 방어 변경 차단, 잘못된 턴/경기/중복 명령 무시.
- 협동 공 소유권 분할, 조작권 교대, 각 소유자의 패시브·크기·능력 배율 적용, 체인 재가속 권한 확인.
- PvP 친구의 빨강 승리 보상과 협동 양쪽 보상 저장, 중복 스냅샷에 의한 보상 중복 지급 차단.
- 연결 종료 시 로비 복귀 및 중도 포기 보상 차단. LAN 중 P키 비활성화, 종료 후 오프라인 P키 복구.
- 잘못된 JSON, NaN, 과도한 중첩 데이터 수신 시 연결 종료. 프레임·버퍼 크기 제한, 연결/수신 타임아웃 사용.

## 보스 / 스킨 / 회귀 검증

- 보스 3종 서로 다른 패턴, 실제 속도 변화, 접촉 피해, 장외 피해, 협동 체력 배율.
- 노곡빈 1페이즈 종료 시 생존·얼굴/체력 전환. 1페이즈만 종료하면 보상 없음.
- 2페이즈까지 처치하면 붉은 스킨 저장. 동일 경기 보상은 한 번. 뽑기 3,000회에서 보스 전용 스킨 제외 확인.
- 사진 스킨 6종 표시 전후 반경·질량·좌표 불변. 구비 투명 여백 제거 후 지름에 맞춘 렌더링.
- 기존 v1/v2 저장 보존 및 v3 전환. 부적절한 전용 스킨 해금 데이터 정리.
- 기존 12패시브·8스킬·CPU·물리·UI·오디오·실행기 테스트 유지. 타이거 샷 배율 2/1.8, 풍압 97.5, 쿨타임 8턴으로 변경.
- 추가 검사 중 발견한 준비 시간 초과 직후 다음 턴의 방어가 자동 확정되던 문제 수정.

## 직접 확인하지 못한 항목

서로 다른 **Windows PC 두 대**에서의 방화벽/공유기 접속, Windows 배치파일과 네이티브 창 흔들림의 실기 동작, 실제 스피커 청취, 장시간 플레이 밸런스는 이 Linux 환경에서 검증하지 못했습니다. LAN은 IPv4/TCP 24872 직접 접속이며 인터넷 매칭/재접속 복구는 미구현입니다. 보스와 신규 사진 스킨은 구현되어 있고, 보스 전용 음원은 아직 제공되지 않아 기존 전투 음악·합성 효과음을 사용합니다.

## 재현

```bash
python -m pip install -r requirements.txt
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy python -m unittest discover -s tests
python check_sfx.py --headless
python main.py
```

Windows에서는 `test_windows.bat`, `play_windows.bat`를 사용합니다. 자세한 LAN 조작은 루트 `README_KO.md`, 필요한 음원 파일명 전체는 `ASSETS_KO.md`에 있습니다.
