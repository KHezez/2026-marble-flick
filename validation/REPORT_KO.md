# v0.7 실행·자동 테스트 결과

검증 날짜: 2026-10-23. Linux x86_64, Python 3.12.14, Pygame 2.6.1 / SDL 2.28.4.
화면과 오디오는 SDL dummy 드라이버를 사용했습니다. 저장 파일은 테스트별 임시 폴더로 분리했습니다.

## 결과

- 자동 테스트 **120개 통과, 실패 0개, 스킵 0개**. 기존 회귀 테스트 87개와 v0.7 신규 33개입니다.
- 기존 기대값 중 이번 요청으로 달라진 P키 지급, 방어 스킬 역할, 탭/슬롯 기반 인벤토리 동작을 새 규칙에 맞춰 검증했습니다.
- `python check_sfx.py --headless`: 등록된 효과음 **46개 모두 재생 채널 활성화**. 제공 파일은 실제 디코딩, 미제공 파일은 합성 대체음입니다.
- BGM **12개 장면** 전환에서 실제 믹서 재생을 확인했습니다. 네 곡은 포함 음원, 신규 8개 장면은 기존 곡 대체 경로입니다. Ogg/WAV/FLAC 헤더 감지 코드를 추가했고, WAV가 .mp3로 저장된 경우 실제 재생을 테스트했습니다.
- 전체 소스 문법 컴파일 및 변경 파일 공백 검사(원문 그대로 포함한 제3자 글꼴 라이선스 제외).
- 배포 ZIP을 새 폴더에 풀어 메뉴 5개·인벤토리 4탭·맵 6개·저주 시전/방출·실제 실행/종료 루프를 다시 실행했고 정상 완료했습니다.
- 한글·영문 홈/설정/상점/경기 설정/인벤토리의 스킬·패시브·스킨·스탯 탭, 아이템 설명, 6개 맵을 실제 Pygame 렌더 경로로 실행했습니다. 한국어 글꼴과 PNG 파일도 로드했습니다.

재현 명령(설치된 Python 기준):

```text
python -m unittest discover -s tests -v
python check_sfx.py --headless
```

Windows에서는 `test_windows.bat`를 사용합니다. 로그는 `validation/v07/tests.log`, `audio.log`에 있습니다. 같은 폴더에 실제 렌더링한 화면 PNG를 첨부했습니다. 이 화면들은 500코인·테스트용 장착의 별도 프로필로 생성했습니다.

## 신규 기능 검사

- Bull 공격: 속도 +50%, 같은 충돌 속도에서 파워 전달 +50%, 나무 파괴.
- Bull 방어: 적 정지 → 후퇴 → 돌진 → 밀치기·3턴 부상. 중간에 정지해 있어도 물리 턴이 끝나지 않음. 장애물 너머로 카운터하지 않음.
- 무하한: 고속 적이 실제 접촉 전에 차단됨. 사용자 위치 고정, 부상·Cola 폭발·Tiger 풍압 면역.
- 앵클 브레이커: 옆 회피와 무적 만료, 공격자 진행 방향 유지, 경계에서 공격자만 탈락.
- 저주: 11턴부터 가능, 경기당 한 번, 클러치에도 재사용 불가. 1.8초 시전 중 실제 좌표는 유지하고 이후 무작위 최대 당김 속도 적용. 이전 Tiger/Curve 등의 플래그 잔류 제거. 면역 대상 예외.
- 새 방어 스킬이 빗나가도 쿨타임 소비, 턴 종료 시 해제. CPU가 공격/방어 역할에 맞는 스킬만 선택.
- 천안: 방어 확정 전 비공개, 확정 후 정확한 구슬 ID·능력 이름 저장, 전용 음향 한 번, PNG/표적 렌더, 기존 8턴 쿨타임.
- 지역 얼음/진흙: 마찰에 따른 실제 감속 차이, 진흙 지역 진입/이탈 시 조준 오차 변경.
- 강철 링: 경계 반사, 13턴 개방, 개방 이후 장외. 돌파 맵: 연속된 파괴 가능 목재 벽.
- 6개 맵에서 Heavenly/Juggernaut/Friendship 및 Rat/Sniper/Curve 조합의 비중첩 생성, 고속 Tiger 이동 중 유한 좌표와 속도 상한.
- 스킨 100코인 차감, 중복 40코인 환급, 장착/언어/설정 저장 후 재로드.
- 슬롯 교체·교환, Heavy/Juggernaut 상호 배타성, 기존 v1 코인·장착·스탯·빨강 로드아웃 보존.
- F10 일시 정지 중 준비 시간 유지, 설정 저장 후 경기 복귀.
- 렌더링이 물리 좌표를 변경하지 않음, 파티클 400개·스프라이트 32개 제한.
- 창 흔들림 기본 꺼짐. 가짜 SDL 창으로 원위치 복원 검사. 조준 및 체인 재가속 방향 선택 중 창 이동 차단.
- 실행기가 잘못된 Python보다 실제 Pygame이 설치된 인터프리터를 우선 선택하고, 설치가 필요하면 지원되는 64비트 Python만 고르는 로직 검사.

## 검사 중 발견해 수정한 문제

1. Bull 카운터가 벽 너머의 상대에게 발동하던 문제: 구슬 반경을 고려한 경로 검사 추가.
2. 강한 패시브/Tiger/반동 조합에서 같은 접촉에 파워가 반복 증폭되어 NaN 또는 과도한 서브스텝을 만들던 문제: 접촉별 파워 보정 간격 0.08초, 최고 속도 18,000px/s로 수치와 연산량 제한.
3. 저주가 이전 공격의 Tiger·Curve 플래그를 물려받던 문제: 시전 방출 시 이전 공격 상태 초기화.
4. 가변 한국어 폰트 기본 축이 너무 얇게 렌더링되던 문제: Noto Sans KR 400/700 고정 인스턴스 포함.

## 미검증 및 범위

**직접 검증하지 못한 항목:** Windows에서 배치파일 실제 실행, SDL 네이티브 Windows 창 이동, 실제 스피커 청취, 화면 입력 지연/FPS, 장시간 수동 플레이와 대전 밸런스. 더미 드라이버 결과는 실제 출력 장치의 동작을 보증하지 않습니다. 실험적 창 흔들기는 기본 꺼짐이며 설정에서 켤 수 있습니다.

사용자 제공 `노곡빈.png`는 아직 없으므로 미제공 대체 배경과 테스트용 이미지 주입 경로를 검증했습니다. 새 BGM·효과음은 사용자 추가 후 실제 청취가 필요합니다. 전체 파일명은 루트 `ASSETS_KO.md`를 참고하세요.

멀티플레이, 실결제, 서버 재화 검증, 스킨 능력치, 여러 로드아웃 선택 UI는 이번 범위가 아닙니다. 계획했던 액티브 8종은 모두 구현했습니다. 이전 `validation/`의 v0.6 로그/화면은 과거 기록이며, 현재 결과는 이 보고서와 `v07/` 폴더입니다.
