# Marble Flick v0.6

첨부된 v0.5의 `main.py`, `physics.py`, `cpu.py`, `stats.py`, `abilities.py`와 기존 46개 테스트를 기반으로 확장한 로컬 Pygame 게임입니다. 물리, 준비/공개/발사 단계, 바닥, 장애물, CPU 후보 탐색 구조를 유지합니다. UI는 영어 짧은 표기를 사용하고 이 설명서는 한국어로 제공합니다.

## Windows 실행

1. ZIP을 쓰기 가능한 폴더에 **모두 압축 해제**합니다.
2. **Python 3.12 64비트**를 설치합니다. PowerShell에서 `winget install -e --id Python.Python.3.12`로 설치할 수 있습니다. 설치 후 터미널을 새로 여세요. 기존 Python은 제거할 필요 없습니다.
3. `play_windows.bat`를 더블클릭합니다. 최초 실행은 인터넷으로 Pygame 2.6.1을 설치합니다. 이후에는 로컬 `.venv-py312`를 재사용합니다. 기존 `.venv`는 건드리지 않습니다. 소스 빌드 대신 검증된 설치용 wheel만 받습니다.
4. 개발 테스트는 `play_dev_windows.bat`를 사용합니다. 일반 실행에서는 P키가 화폐를 만들지 않습니다.
5. 설치 후 자동 테스트는 `test_windows.bat`를 실행합니다.

수동 실행:

```text
py -3.12 -m venv .venv-py312
.\.venv-py312\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.\.venv-py312\Scripts\python.exe main.py
```

Windows에서 `pygame-2.6.1.tar.gz`, `Getting requirements to build wheel`, `distutils.msvccompiler` 오류가 나온다면 현재 Python 버전/아키텍처에 맞는 wheel을 찾지 못해 소스 빌드를 시도한 것입니다. 위 Python 3.12 64비트 전용 환경으로 설치하세요. 기존 가상환경을 활성화했어도 위 명령은 새 환경의 실행 파일을 직접 지정하므로 별도 활성화가 필요하지 않습니다. `py -3.12`가 없다고 나오면 Python 설치 후 새 터미널에서 다시 실행하세요.

Linux/macOS: 가상환경에 `python -m pip install -r requirements.txt`를 실행한 뒤 `python main.py`를 실행합니다. 유일한 외부 Python 라이브러리는 **pygame==2.6.1**입니다. FFmpeg는 제공 효과음을 변환할 때만 사용했으며 게임 실행에는 필요하지 않습니다. 1280×900 창을 사용하므로 해당 크기 이상의 작업 영역을 권장합니다.

## 게임 시작 및 로드아웃

- **START**: 1v1, 4v4~10v10 / Local 2P 또는 CPU Easy·Normal·Hard / normal·ice·mud / none·wood·steel·mixed를 선택하고 CONFIRM & START.
- **INVENTORY**: 아이템을 클릭하면 설명과 등급, 스킬 쿨타임이 나옵니다. EQUIP / UNEQUIP으로 변경합니다. 노란 ON 카드는 장착 중, LOCK은 미보유입니다.
- 패시브 최대 3개, 액티브 최대 2개이며 아무것도 장착하지 않아도 시작할 수 있습니다.
- BLUE LOADOUT과 RED / CPU를 각각 설정할 수 있습니다. 보유 컬렉션은 이 컴퓨터의 공용 컬렉션이고 두 팀의 스탯/장착은 별도입니다. 상대 선택은 **준비 단계에서** 숨겨지며 장착 목록 자체는 공개입니다.
- 스탯은 정확도 15 / 속도 30 / 파워 30 / 맷집 30 / 치명 10, 합계 50점. +, -, +5 버튼으로 분배합니다. 경기 중에는 배분과 장착 변경을 할 수 없습니다.
- 천여주박을 어느 팀이든 장착했다면 1v1 선택이 차단됩니다. 먼저 해제해 주세요.
- 두 팀의 승패 보상은 한 로컬 플레이어 프로필 기준입니다. **파랑 승리 100 Coins, 파랑 패배 또는 무승부 50 Coins**. 결과 처리는 경기당 한 번입니다. 재시작/중도 이탈에는 보상이 없습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 왼쪽 드래그 | 자신의 구슬에서 발사 반대 방향으로 당긴 뒤 놓아 공격 확정 |
| 1 / 2 | 장착 스킬 슬롯 선택 |
| E → 자신의 구슬 클릭 | 선택 스킬 준비/같은 스킬 취소 |
| Space / READY | 방어 준비 확정 |
| E (Chain 적중 직후) | 마우스 방향 재가속. 제한 시간 1.75초 |
| C | Curve Shot 장착 시 0 → +0.75 → +1.5 → -1.5 → -0.75 → 0 커브 순환 |
| C를 누른 채 휠 | Curve Shot 방향/강도를 0.15씩 미세 조절 |
| Tab | 아직 공격을 잠그지 않은 자신의 공격 턴 넘기기 |
| Esc | 메인 메뉴로 돌아가기(진행 중 경기 종료, 보상 없음) |
| R | 결과 화면에서 재경기 |
| M | 음소거. 메뉴 하단에서 SFX/BGM 볼륨 별도 조절 |
| P | **--dev 실행에서만** 1000 Coins 추가 |
| D / F | 물리 정보 / 시뮬레이션 2배속 |
| F1·F2·F3 / J·K·V | --dev 전용 바닥 변경 / 부상·회복·진흙 실험 |

준비 시간은 한 공격 턴당 25초입니다. 양쪽 준비가 끝나면 0.63초 공개 연출 후 발사합니다. 로컬 2P는 한 마우스를 번갈아 사용합니다. 공격 방향을 잠그고 방어자에게 조작을 넘깁니다. 잠근 조준선과 상대의 준비 스킬 표시는 공개 시점까지 숨겨집니다. 단일 화면을 실제로 보지 못하게 만드는 네트워크 비밀 보장은 아닙니다.

## 12개 패시브

| 패시브 / 등급 | 적용 |
|---|---|
| Heavenly Restricted / Legendary | 아군 수 ceil(N/2), 속도·파워·맷집·정확도·치명 확률 ×2. 치명 20%→40%. 크기는 전투 스탯과 별도이며 이 패시브만으로는 커지지 않음. 1v1 금지 |
| Heavy / Common | 실제 반경·파워·맷집 ×1.25, 속도 ×0.75 |
| Juggernaut / Rare | 실제 반경·파워·맷집 ×1.5, 속도 ×0.5. Heavy와 상호 배타 |
| Sniper / Rare | 오차 부채꼴 ÷1.5, 속도 ×1.2 |
| Last Resort / Epic | 최후의 한 알에 현재 공격 턴이 끝날 때까지 개인 경계벽. 경기당 한 번. 같은 물리 스텝에 두 알이 탈락해도 첫 탈락 직후 재평가 |
| Metal / Common | 맷집 ×1.3, 속도 ×0.8 |
| Tungsten / Rare | 맷집 ×1.6, 속도 ×0.65, 부상 지속 -1 소유자 공격 턴 |
| Rat / Common | 반경·맷집 ×0.7, 파워 ×1.15, 속도 ×1.3 |
| Sleeper Build / Rare | 반경·맷집 ×0.85, 파워 ×1.3 |
| Curve Shot / Epic | C/휠 입력으로 실제 속도 벡터 회전. 커브는 이동 중 지수 감쇠. 점선은 방향 안내이며 충돌 결과 예측은 아님 |
| Eyes of Heaven / Legendary | 자신의 공격 턴에 방어 확정된 상대 스킬 이름 감지. 대상 구슬 위치는 알려주지 않음. 8개 공격 턴 쿨타임 |
| Power of Friendship / Epic | 중심 간 95px 이내 아군이 자신 포함 2개 이상이면 알당 맷집 +5%(두 알 +10%), 최대 +25%. 매 충돌 시 위치로 재계산, 녹색 테두리 |

Last Resort를 1v1에서 장착하면 첫 공격 턴에만 보호가 생깁니다. 1v1은 처음부터 한 알이므로 클러치 초기화는 없습니다. 2개 이상에서 1개로 줄어들면 경기당 한 번 장착 스킬 쿨타임이 즉시 초기화됩니다. Last Resort와 클러치는 서로 독립입니다.

계산은 기존 스탯 수식 → 패시브의 곱 → 부상 → 스킬 보정 순서로 해석합니다. 곱 계열은 장착 순서에 영향을 받지 않습니다. 정확도는 오차각 나누기, 확률은 곱 후 100% 상한, 실제 반경은 크기 패시브의 곱이며 부상으로 크기가 변하지 않습니다. 부상은 기존처럼 주요 전투 출력 50%, 정확도 오차각 2배, 속도에 의한 마찰 감소 보너스 절반이며 중첩되지 않습니다. 기본 2회 소유자 공격 턴, Tungsten 1회입니다. 스킬 쿨타임/Last Resort는 양 팀의 공격 턴을 모두 셉니다.

## 기존 네 스킬

- **Brickwall**: 고정 충돌체, 반경 ×1.75, 부상 제거·면역. 공격 사용 2턴/방어 사용 1턴, 쿨타임 6. 벽으로 만든 구슬 자체는 발사할 수 없습니다.
- **Tiger Shot**: 한 공격의 속도·파워 ×3, 오차 0, 목재 즉시 파괴, 근처 구슬 풍압, 쿨타임 7.
- **Chain**: 상대 적중 후 E로 재가속, 최대 5회, 회차마다 속도·파워 ×0.78 계열 감쇠, 쿨타임 10.
- **Coca Cola Espuma**: 발사 구슬이 멈추면 반경 177px 충격파. 아군이 둘 이상이면 발사 구슬 희생, 마지막 한 알이면 생존. 쿨타임 7. 발사 전에 장외로 떨어진 구슬은 폭발하지 않습니다.

방어용은 현재 Brickwall만이며 맞지 않더라도 공개 후 소모/쿨타임이 적용됩니다. Bull, Ankle Breaker, 노곡빈의 저주, 무하한은 `FUTURE_SKILLS` 메타데이터만 준비했습니다. 장착·뽑기 풀에는 포함하지 않습니다.

## Coins와 뽑기

새 프로필: 500 Coins, Brickwall/Tiger Shot, Heavy/Sniper/Metal 보유. 나머지는 뽑기로 획득합니다. Chain/Cola는 기존 구현을 그대로 확장하여 상점에서 해금합니다.

- 패시브 뽑기 150, 스킬 뽑기 200 Coins.
- 등급 확률: Common 60%, Rare 25%, Epic 12%, Legendary 3%.
- 해당 등급 안에서는 모든 아이템이 동일 확률입니다. 패시브는 Common 3종/ Rare 4종/ Epic 3종/ Legendary 2종이므로 개별 확률은 각각 20% / 6.25% / 4% / 1.5%입니다.
- 스킬은 Brickwall Common 60%, Tiger Rare 25%, Chain Epic 12%, Cola Legendary 3%입니다.
- 중복은 구매가의 40% 환급: 패시브 60, 스킬 80 Coins. 뽑기 시작 즉시 결과를 저장하고 1.4초 연출 후 공개합니다.
- 로벅스/현금 결제 없음. 개발 모드는 로컬 테스트 편의 기능이며, 향후 온라인에서는 서버 권한 화폐 처리가 별도로 필요합니다.

`user_data/profile.json`에 화폐, 소유 목록, 최근 100회 뽑기 결과, 스탯, 양 팀 장착, 볼륨을 저장합니다. 임시 파일 → 원자적 교체와 `.bak` 백업으로 저장 중 손상에 대비합니다. JSON의 `loadouts`/`active_loadout`은 향후 여러 프리셋을 지원할 구조이며 현재 UI에서는 파랑 1개와 빨강 1개를 편집합니다. 다른 저장 경로가 필요하면 `MARBLE_SAVE_PATH` 환경변수를 설정합니다. 저장 실패는 화면에 표시됩니다.

## 효과음과 이미지

**전체 파일명과 용도: [ASSETS_KO.md](ASSETS_KO.md)**

- `assets/sfx/*.mp3`: 실제 MP3 인코딩 파일. 기존 제공 17개는 변환된 실제 MP3가 포함되어 있습니다. 신규 14개는 아직 없으며 서로 다른 합성 대체음이 자동 재생됩니다.
- `assets/music/*.mp3`: 화면별 BGM. 사용자 제공 4곡의 실제 MP3 변환본이 포함되어 있습니다. 파일을 제거해도 무음으로 정상 실행됩니다. 300ms 페이드아웃 → 새 곡 500ms 페이드인.
- `assets/themes/*.png`: 미제공 상태는 기본 배경. 메인·상점·인벤토리는 1280×900, 경기장 타일은 560×675 권장.
- `python check_sfx.py`는 디코딩과 실제 채널 재생을 검사합니다. `--headless`는 소리 출력 없이 같은 경로를 검사합니다. `python main.py --audio-debug`로 호출 로그를 자세히 볼 수 있습니다.

Cola 오류는 파일명이 아닌 실제 포맷 문제였습니다. 원본 두 파일은 `.mp3`라는 이름의 MP4/AAC였으며 Pygame 2.6.1에서 `Unrecognized audio format`이 재현되었습니다. 나머지 기존 효과음도 실제로는 Ogg/Vorbis였습니다. v0.6은 실제 MP3로 변환했고 로딩 오류를 숨기지 않습니다. Cola 충전/폭발/클러치/결과에는 전용 채널을 두고, 폭발과 희생에서 소리가 중복 호출되던 경로를 제거했습니다. 자세한 근거는 `validation/REPORT_KO.md`에 있습니다.

## 구현과 검증 범위

구현: 패시브 12종, 네 스킬과 확장 레지스트리, CPU 세 난이도/로컬 2P, 준비 비공개·공개, 경기 전 스탯, 영속 프로필, 화폐/뽑기/중복 환급, 밝은 메뉴 UI, 실제 반경/커브/군집 버프, 클러치, 효과음 진단, 별도 음악 볼륨, PNG 교체, 충격파·섬광·화면 흔들림·짧은 히트스톱·줌·트레일·파티클 상한 400개.

미구현(요청 범위 밖): 나머지 네 스킬의 실제 전투 동작, 온라인 대전/서버 보안, 현금 결제, 여러 프리셋 선택 UI, EXE 패키징. 고정 창 해상도이며 한국어 게임 내 텍스트 번역은 포함하지 않습니다.

검증 결과/제약: `validation/REPORT_KO.md`. Linux SDL 더미 화면·오디오로 자동 테스트, 실제 메뉴 클릭/프레임 렌더링/CPU 턴/발사→Cola 폭발 경로를 실행합니다. Windows OS, 실제 스피커 청취 및 사람이 여러 경기를 플레이하는 장기 밸런스 평가는 이 실행 환경에서 검증하지 못했습니다.
