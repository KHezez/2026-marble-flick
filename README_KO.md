# Marble Flick v0.7 사용 설명서

제공된 v0.6 프로젝트를 확장했습니다. 기존 물리·CPU·준비/공개/발사·스탯·12패시브를 유지하고, 한글 UI, 8스킬, 6맵, 11스킨(기본 포함), 새 그림과 VFX를 추가했습니다.

## 설치와 기존 기록 유지

1. 전체 ZIP을 압축 해제한 뒤 `play_windows.bat`를 실행합니다.
2. 실행기는 **실제로 Pygame 2.6.1을 불러올 수 있는 Python**을 먼저 찾습니다. 기존 `.venv*`와 설치된 Python 3.13/3.12/3.11을 확인하며 WindowsApps 별칭은 후보에서 제외합니다.
3. 사용 가능한 Pygame이 없으면 Python 3.11~3.13 64비트로 `.venv-game`을 만들고 바이너리 wheel로 설치합니다. 기존 가상환경은 삭제하지 않습니다. 최초 설치에만 인터넷이 필요합니다.
4. `play_dev_windows.bat`는 추가 디버그 기능과 오디오 로그를 켭니다. **이번 로컬 테스트 버전은 일반 실행에서도 P키를 누를 때마다 1,000 Coins를 지급합니다.**
5. 자동 테스트는 `test_windows.bat`입니다.

사용 중인 정상 Python을 직접 지정해도 됩니다. PowerShell 예:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" main.py
```

VS Code는 `Ctrl+Shift+P` → `Python: Select Interpreter` → `Enter interpreter path`에서 위 Python313의 `python.exe`를 선택하세요. 실행기 콘솔에도 실제 선택한 Python 경로가 표시됩니다.

**기존 기록:** 새 버전 파일을 기존 게임 폴더에 덮어쓰면 `user_data/profile.json`은 그대로 유지됩니다. 새 폴더로 옮길 때는 기존 `user_data` 폴더도 복사하세요. ZIP과 GitHub에는 개인 저장 파일이 들어 있지 않습니다. v1 저장 파일은 돈·아이템·두 팀의 스탯과 장착을 보존하며 v2로 자동 확장됩니다. 여러 로드아웃 데이터 구조는 유지되며 별도 프리셋 선택 UI는 아직 없습니다.

Python 외 필수 라이브러리는 `pygame==2.6.1` 하나입니다. Linux/macOS에서는 가상환경에 `pip install -r requirements.txt` 후 `python main.py`를 실행합니다. 1280×900 창 기준이며 해당 크기 이상의 작업 영역을 권장합니다.

## 메뉴와 설정

- 시작: 1대1 또는 4대4~10대10, 로컬 2인 또는 CPU 쉬움/보통/어려움, 맵을 선택합니다.
- 인벤토리: **오른쪽 사각 슬롯 → 왼쪽 아이템 그림 → 장착** 순서입니다. 스킬 최대 2개, 패시브 최대 3개. 이미 장착된 아이템은 슬롯끼리 교환합니다. 빈 슬롯은 앞에서부터 채웁니다.
- 파랑과 빨강/CPU의 장착·스탯·스킨을 각각 지정합니다. 소유 컬렉션은 이 컴퓨터의 공용 컬렉션입니다.
- 스탯 탭: 정확도 15 / 속도 30 / 파워 30 / 맷집 30 / 치명 10, 합계 50점. 경기 중에는 변경할 수 없습니다.
- 설정: 한국어/English, 효과음·BGM 개별 볼륨, 음소거, 화면 흔들림, 타격 정지, 섬광, 실험적 창 흔들림을 변경합니다. 저장 후 재실행해도 유지됩니다.
- 경기 중 **F10**은 경기를 일시 정지하고 설정을 엽니다. 뒤로 또는 Esc로 돌아옵니다. 경기 중 **Esc**는 현재 경기를 끝내고 메뉴로 이동합니다.
- 실제 Windows 창 흔들기는 기본 **꺼짐**입니다. Windows/SDL에서 지원할 때만 최대 8px 정도 이동하고 효과가 끝나면 원래 위치로 복원합니다. Linux/macOS에서는 적용하지 않습니다. 물리 좌표를 이동시키지 않습니다.

계산은 기존 스탯 수식 → 패시브의 곱 → 부상 → 스킬 보정 순서로 해석합니다. 곱 계열은 장착 순서에 영향을 받지 않습니다. 정확도는 오차각 나누기, 확률은 곱 후 100% 상한, 실제 반경은 크기 패시브의 곱이며 부상으로 크기가 변하지 않습니다. 부상은 기존처럼 주요 전투 출력 50%, 정확도 오차각 2배, 속도에 의한 마찰 감소 보너스 절반이며 중첩되지 않습니다. 기본 2회 소유자 공격 턴, Tungsten 1회입니다. 스킬 쿨타임/Last Resort는 양 팀의 공격 턴을 모두 셉니다.

## 상점, 스킨과 보상

새 프로필은 500 Coins와 브릭월/타이거 샷, 헤비/스나이퍼/메탈을 보유합니다. 새 스킬도 뽑기 풀에 들어 있습니다.

- 패시브 150 Coins, 스킬 200 Coins, **스킨 100 Coins**.
- 등급 확률: 일반 60%, 희귀 25%, 영웅 12%, 전설 3%. 같은 등급 내 각 아이템은 같은 확률입니다. 상점 화면에도 표시합니다.
- 중복은 뽑기 가격의 40% 환급: 패시브 60 / 스킬 80 / 스킨 40 Coins.
- 기본 스킨 + 루비·선셋·레몬·에메랄드·오션·바이올렛·레인보우·갤럭시·타이거·황금. 스킨은 능력치를 바꾸지 않습니다. 바깥 팀 색상 링으로 아군/적군을 구분합니다.
- 파랑 승리 100 Coins, 패배/무승부 50 Coins. 경기당 한 번만 지급합니다. 중도 이탈에는 보상이 없습니다.

## 그림, 효과와 음원

스킬 8개·패시브 12개 각각의 그림, 고유 선택 테두리 8개, 버튼 패널, 타격 스프라이트, 천안 PNG, 사막/정글 배경을 포함합니다. 아이템 그림은 PNG 시트의 개별 칸으로 관리합니다. 스킨 패턴은 런타임에 그립니다.

파티클 최대 400개, 충격파/스프라이트 최대 32개, 확대·흔들림은 경기장 렌더에만 적용됩니다. 반복 반동 시 같은 접촉의 파워 보정을 0.08초 내 재적용하지 않고 최고 속도를 18,000px/s로 제한하여 수치 폭주와 무한 서브스텝을 막습니다.

BGM은 맵 테마 → 클러치 테마(`clutch.mp3`), 저주 시전 중은 `curse.mp3`로 전환합니다. 새 곡이 없으면 기존 `match.mp3`, 설정 곡이 없으면 `main_menu.mp3`를 사용합니다. 0.3초 페이드 아웃 후 0.5초 페이드 인. 음악이 전혀 없어도 게임은 실행됩니다.

**음원 전체 파일명과 PNG 경로는 [ASSETS_KO.md](ASSETS_KO.md)에 있습니다.** 기존 사용자 효과음과 네 곡의 변환된 BGM을 포함합니다. 신규 미제공 효과음은 합성 대체음입니다. 확장자만 .mp3로 바꾼 파일 대신 실제 MP3 인코딩을 권장하며 BGM 로더는 Ogg/WAV/FLAC 헤더도 판별합니다. MP4/AAC 파일은 MP3로 변환해야 합니다.

## 검증과 남은 범위

검증 결과 및 재현 명령은 [validation/REPORT_KO.md](validation/REPORT_KO.md)에 있습니다. Windows 실제 창 흔들림·배치 실행·스피커 청취와 장시간 플레이 밸런스는 Linux 환경에서 검증하지 못했습니다.

온라인/로컬 네트워크 멀티, 실결제, 서버 재화 검증, 스킨의 추가 능력, 여러 로드아웃을 고르는 프리셋 UI는 이번 범위에 포함하지 않았습니다. P키 무료 지급은 요청대로 현재 로컬 테스트 단계에 활성화했습니다.
